Project Overview

AI Travel Planner is an intelligent travel planning platform that helps users create personalized travel plans based on destination, duration, budget and preferences. It consolidates itinerary creation, budget estimation and e-ticket generation into a single, easy-to-use web experience.

The problem

Traditional travel planning forces users to visit multiple sites to gather destination details, hotels, transport options and budgets. This is time-consuming and fragmented.

The solution

AI Travel Planner combines rule-based AI assistant logic, voice interaction and local utilities (pdf export, local storage) to provide quick, personalized itineraries and budgets — all in a privacy-friendly, browser-first demo app.

Key Features (Implemented)

AI Travel Assistant

Rule-based assistant generates day-wise plans and answers travel queries (plan, budget, safety, hotels).

Voice Interaction

Assistant speaks responses using browser SpeechSynthesis for a natural demo experience.

Personalized Itineraries

Generate day-by-day suggestions based on destination and duration, editable by the user.

Smart Budget Planning

Quick estimates for hotel, food, travel and misc costs to help users plan a realistic budget.

Basic Hotel Suggestions

Static tiered hotel suggestions (premium/mid/budget) included in assistant replies.

Save Trips Locally

Bookings and trips are stored in localStorage so demos remain fast and private.

PDF / Ticket Generation

Download e-tickets using jsPDF (client-side only, no server required).

Responsive Design

Designed to work on phones, tablets and desktops — ideal for recruiter demos on any device.

Security & Privacy

This demo is browser-first and privacy-friendly. Key notes and recommendations:

  • Protect user information — demo uses localStorage; do not store sensitive secrets there in production.
  • Avoid exposing API keys in frontend code. Move secrets to a backend when integrating real services.
  • Validate and sanitize user input before processing or sending to any API.
  • Use secure database access, authentication and authorization for production systems.
  • In the demo, authentication and payment integrations are not implemented.
